# Khyber Seed Portal

Build a modern, professional, mobile-first agricultural seed company website for a company called “Khyber Seed”.

1. Company Overview

Khyber Seed is an agricultural seed company that sells high-quality and scientifically improved/modified seeds for different crops.

The company offers seeds for crops including:

Wheat

Cotton

Rice

Corn / Maize

Vegetables

Fodder crops

Oilseed crops

Pulses

Other agricultural seeds

The website should communicate trust, agricultural expertise, quality, innovation, and reliability.

The overall design should feel like a professional agricultural brand — clean, premium, modern, trustworthy, and not like a generic farming template.

2. Technology Requirements

Build the website using:

React

TypeScript

Tailwind CSS

Modern reusable React components

Responsive design

Mobile-first approach

Structure the project cleanly so that components can easily be reused and expanded later.

Use realistic dummy data for products, categories, testimonials, statistics, and company information.

Do NOT create a backend or authentication system at this stage.

3. Design Direction

Use a strong agricultural visual identity.

Primary colors

Use:

Deep agricultural green as the primary color

Dark green for headings and navigation

Light/soft green for backgrounds

White for clean sections

Subtle yellow/golden accents inspired by wheat and crops

Avoid excessive gradients.

The design should feel:

Premium

Clean

Modern

Professional

Agricultural

Trustworthy

Corporate but approachable

Use rounded cards, subtle shadows, clean spacing, modern typography, and high-quality agricultural imagery.

Avoid making the website look overly colorful or cartoonish.

4. Mobile-First Navigation

This is very important.

The website must be designed mobile-first.

On desktop/tablet:

Create a traditional top navigation/header.

Navigation items:

Home

About Us

Seeds

Crops

Why Khyber Seed

Contact

Add a prominent CTA button:

“Explore Seeds”

On mobile:

Use a fixed bottom navigation bar instead of relying only on a hamburger menu.

The bottom navigation should remain visible while scrolling.

Mobile bottom navigation tabs:

Home

Seeds

Crops

About

Contact

Each tab should have a clean modern icon and label.

The active tab should have a clear visual state using the primary green color.

The bottom navigation should have:

White background

Subtle top border/shadow

Rounded/top corners if appropriate

Safe-area padding for modern phones

Fixed positioning

Proper spacing for thumb-friendly interaction

Add enough bottom padding to the page content so the fixed navigation never overlaps content.

On desktop, hide the bottom navigation and show the normal header navigation.

26. Important Design Rule

Do NOT make this look like a simple template.

The final result should look like a real, established agricultural seed company website that could be presented to customers, farmers, distributors, and business partners.

Prioritize:

Trust → Product Quality → Agriculture → Professionalism → Conversion

The primary goal of the website is to make visitors understand what Khyber Seed offers, explore available seed varieties, trust the company, and easily contact the company for product information or availability.

Start by building the complete responsive UI with realistic demo content and polished interactions.
